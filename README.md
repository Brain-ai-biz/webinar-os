# Webinar-OS · וובינר חי שלם, ב-7 שלבים, בלי מקום לטעות

הפקת וובינר היא 15 משימות קטנות על 8 כלים: מחקר, מצגת, תסריט, דף הרשמה, דף תודה, קבוצה, מיילים, וואטסאפים, זום. כל אחת "קטנה", וביחד זה שבוע, ותמיד שוכחים משהו.

**Webinar-OS** הוא סקיל ל-Claude Code. כותבים `/webinar-os`, עונים על 8 שאלות תוכן (ועוד 3 קצרות על הטון; בשלבים 2 ו-3 יש עוד שאלת בחירה קצרה אחת בכל שלב: מצגת HTML או מתווה, ונרשמים לגיליון או כפתור לקבוצה), ו-Claude מוביל/ה אותך ב-7 שלבים קבועים, באותו סדר, כל שלב מסתיים בקבצים מוכנים ובהוראה ידנית של דקה-שתיים. שני אישורים בדרך (קופי הדף, התזכורות). כל הריצה: כ-60-90 דקות, מתוכן 3-5 דקות שקטות במחקר של שלב 1 (ב-Windows עד 5) ו-8-12 דקות שקטות בשלב 2. זה תקין, ככה זה נמדד. אם עברו 15 דקות בלי כלום, זה הזמן לבדוק. בזמן הריצה Claude יבקש אישור לפני כל הרצת סקריפט או פתיחת קובץ; לוחצים Yes (או "Yes, don't ask again" לפקודה הזו). בלי מפתחות API, בלי חיבורים, בלי שאלות עיצוב. עובד אצל כולם, ב-Mac וב-Windows, בחינם.

## התקנה ב-3 צעדים

**לפני שמתחילים:** צריך Claude Code מותקן ומחובר לחשבון. אין? נכנסים ל-claude.com/code, מתקינים לפי ההוראות שם, פותחים טרמינל חדש ומריצים `claude` פעם אחת כדי להתחבר. רק אחרי שזה עובד ממשיכים לצעד 1.

1. יוצרים (או בוחרים) תיקיית פרויקט שבה תעבדו, למשל תיקייה ריקה בשם `webinars` בתוך Documents.
2. מורידים את הזיפ ופותחים אותו **בתוך התיקייה הזו**. מקבלים שם תיקייה בשם `webinar-os`. (חשוב: Claude Code קורא רק קבצים בתוך תיקיית הפרויקט; זיפ שנשאר ב"הורדות" הוא לא רואה.)
3. פותחים טרמינל (Mac: Terminal, Windows: PowerShell), מקלידים `cd ` ואז גוררים את תיקיית הפרויקט לחלון, Enter, ואז מקלידים `claude` ו-Enter. (הטרמינל עונה `claude: command not found` או `'claude' is not recognized`? Claude Code לא מותקן, או שהטרמינל נפתח לפני ההתקנה: ראו "לפני שמתחילים" למעלה, ואת `skills/webinar-os/reference/troubleshoot.md` שורה 0.) כש-Claude Code נפתח, מדביקים לו את הפרומפט הזה:

```
התקן/י את הסקיל webinar-os מהתיקייה webinar-os (בתוך הפרויקט) לפי הקובץ INSTALL.md שבתוכה. בסוף אמור/י לי שהכל תקין ומה הפקודה להפעלה.
```

לא בטוח/ה בנתיב? גורר/ת את התיקייה `webinar-os` לחלון הטרמינל והנתיב המלא יודבק לבד.

בדרך Claude Code יבקש כמה בקשות הרשאה (העתקה לתיקייה `.claude/`, הרצת Python, יצירת תיקייה): מאשרים כל אחת, זו הגנה של Claude Code, לא תקלה. מכאן Claude מעתיק/ה את הסקיל ל-`.claude/skills/webinar-os/` בפרויקט, מריץ/ה בדיקה של 5 שניות, ומחזיר/ה "מוכן". מאז: `/webinar-os` בשיחה חדשה, וזה מתחיל מיד בשאלה הראשונה.
