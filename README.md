# Webinar-OS · וובינר חי שלם, ב-7 שלבים, בלי מקום לטעות

הפקת וובינר היא 15 משימות קטנות על 8 כלים: מחקר, מצגת, תסריט, דף הרשמה, דף תודה, קבוצה, מיילים, וואטסאפים, זום. כל אחת "קטנה", וביחד זה שבוע, ותמיד שוכחים משהו.

**Webinar-OS** הוא סקיל ל-Claude Code. כותבים `/webinar-os`, עונים על 8 שאלות תוכן (ועוד 3 קצרות על הטון), ו-Claude מוביל/ה אותך ב-7 שלבים קבועים, באותו סדר, כל שלב מסתיים בקבצים מוכנים ובהוראה ידנית של דקה-שתיים. שני אישורים בדרך (קופי הדף, התזכורות). בלי מפתחות API, בלי חיבורים, בלי שאלות עיצוב. עובד אצל כולם, ב-Mac וב-Windows, בחינם.

## מה מקבלים (7 השלבים)

| # | שלב | מה יוצא |
|---|---|---|
| 1 | מחקר | 8 תשובות + 6-10 עובדות מאומתות עם מקור ולינק → `research.md` |
| 2 | מצגת ותסריט | מצגת HTML (14 מערכות, כ-30-40 שקפים, PDF בלחיצה) + תסריט מתוזמן 2.5 מילים לשנייה → `deck.html`, `script.md` (או מתווה ל-Canva / PowerPoint) |
| 3 | דף נחיתה | דף הרשמה ב-8 סקשנים, נייד-קודם, ספירה לאחור, טופס עם תיבת הסכמה אחת (הנרשמים לגיליון Google) או כפתור לקבוצה → `landing/index.html` |
| 4 | דף תודה | "נשאר צעד אחד: הקבוצה", 3 צעדים, התאריך → `landing/thank-you/index.html` |
| 5 | קבוצת וואטסאפ | שם, הגדרות קבוצה שקטה, קבוצה 2 ב-1,024, הודעת פתיחה → `whatsapp-group.md` |
| 6 | תזכורות | 3 מיילים + 4 הודעות וואטסאפ + לוח שילוח עם תאריכים ושעות מדויקים, מוכנים להדבקה בכל מערכת → `emails.md`, `whatsapp.md`, `schedule.md` |
| 7 | הוובינר | הקמת וובינר בזום (לא פגישה), הודעת "התחלנו", צ'קליסט 10 דקות, ומה סופרים אחרי → `webinar-day.md`, `after.md` |

הכל נשמר ב-`outputs/webinars/<slug>/` בפרויקט שלך. המצגת, הדפים והקריאייטיבים חולקים מערכת עיצוב אחת (כהה, פונט Heebo, צבע הדגשה חם אחד), אז זה נראה מקצועי בלי מעצב/ת. נעצרת באמצע? `/webinar-os המשך` ממשיך מהשלב האחרון שהושלם.

## התקנה ב-3 צעדים

1. מורידים את הזיפ ופותחים אותו **בתוך תיקיית הפרויקט** שבה תעבדו (למשל `webinars/`). מקבלים שם תיקייה בשם `webinar-os`. (חשוב: Claude Code קורא רק קבצים בתוך תיקיית הפרויקט; זיפ שנשאר ב"הורדות" הוא לא רואה.)
2. פותחים Claude Code בתיקיית הפרויקט שבה רוצים לעבוד. אין פרויקט? יוצרים תיקייה ריקה בשם `webinars` ופותחים בה.
3. מדביקים ל-Claude את הפרומפט הזה, עם הנתיב לתיקייה שהורדת:

```
התקן/י את הסקיל webinar-os מהתיקייה <הנתיב לתיקייה webinar-os> לפי הקובץ INSTALL.md שבתוכה. בסוף אמור/י לי שהכל תקין ומה הפקודה להפעלה.
```

בדרך Claude Code יבקש אישור אחד לכתוב לתיקייה `.claude/` (הגנה שלו, לא תקלה): מאשרים. מכאן Claude מעתיק/ה את הסקיל ל-`.claude/skills/webinar-os/` בפרויקט, מריץ/ה בדיקה של 5 שניות, ומחזיר/ה "מוכן". מאז: `/webinar-os` בשיחה חדשה, וזה מתחיל מיד בשאלה הראשונה.

## האם זה יעבוד אצלי?

| יש לי | מה קורה |
|---|---|
| Claude Code על Mac | **כן.** Python 3.9+ כבר מותקן ברוב המחשבים |
| Claude Code על Windows | **כן.** צריך Python מ-python.org (לסמן "Add python.exe to PATH"). הפקודה `python` במקום `python3` |
| בלי אינטרנט בזמן הצפייה | הדפים והמצגת עובדים; רק הפונט נופל לפונט המערכת. העימוד זהה |
| בלי מערכת דיוור | המיילים יוצאים כטקסט מוכן להדבקה; שולחים מ-Gmail ב-BCC או מכל מערכת |
| בלי תוסף וובינרים בזום | הוראות לפגישה רגילה עם ההגדרות הנכונות |
| רוצה מיתוג משלי / חיבורים / קריאייטיבים לרשתות | אחרי הוובינר הראשון: `skills/webinar-os/reference/advanced.md` |
| Claude.ai / ChatGPT בלי Claude Code | best-effort בלבד, בלי אחריות: `skills/webinar-os/reference/other-tools.md` |

**מדיניות פרטיות:** הסקיל שואל על לינק. אין? הוא אומר שצריך אחד לפני שהדף עולה לאוויר, ובונה בכל מקרה. הוא לא מנסח מדיניות בעצמו.

## כללים שהסקיל לא מוותר עליהם

- עברית, פנייה דו-מגדרית, בלי קו מפריד ארוך.
- אף נתון בלי מקור. אין חיפוש? הוא אומר את זה ומבקש עובדות ממך.
- 7 שלבים, סדר קבוע, "ממשיכים?" אחרי כל אחד. בדיוק 2 עצירות אישור.
- כפתור אחד בדף. טלפון חובה. תיבת הסכמה אחת, לא שתיים.
- משנים JSON ומרנדרים; לא עורכים HTML ביד.
