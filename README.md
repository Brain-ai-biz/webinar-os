# Webinar-OS · וובינר חי שלם בפקודה אחת

**הבעיה:** הפקת וובינר היא 15 משימות קטנות שמפוזרות על 8 כלים: דף הרשמה, דף תודה, מצגת, מיילים, וואטסאפים, קריאייטיבים, זום, קבוצה, לינק, לכידת לידים, לוח שילוח. כל אחת "קטנה", וביחד זה שבוע.

**הפתרון:** סקיל ל-Claude Code. כותבים `/webinar-os`, עונים על 8 שאלות תוכן ו-6 שאלות "מה מחובר אצלי", מאשרים פעמיים (קופי, קריאייטיבים), ומקבלים משפך וובינר מלא, **מותאם לכלים שכבר יש לך**. אין לך כלום מחובר? עדיין עובד: הכל יוצא כקבצים + הוראות של 2 דקות לכל רכיב.

## מה מקבלים

| רכיב | מה זה נותן |
|------|-----------|
| מחקר | 6-10 נתונים מאומתים עם מקורות, שנכנסים למצגת ולקופי |
| מצגת LIVE | קובץ HTML מוכן להצגה (14 מערכות, כ-40 שקפים, PDF בלחיצה), או מתווה להדבקה ב-Google Slides / Canva |
| תסריט הגשה | מה אומרים על כל שקף, עם עצירות לשאלות |
| דף הרשמה + דף תודה | 2 קבצי HTML מעוצבים, מותאמים לנייד, נגישים, עם ספירה לאחור ותיבת הסכמה אחת. צבעים ופונט שלך |
| לכידת לידים | Google Form מאחורי הטופס המעוצב (אפס חיבורים), או webhook / מערכת דיוור אם יש |
| קבוצת וואטסאפ + לינק מקוצר | נוצרים אוטומטית אם יש API, אחרת הוראות של דקה |
| 3 מיילים | ברוכים הבאים / מחר / עוד שעה, בקול שלך |
| 4 הודעות וואטסאפ | מחר / היום / עוד שעה / התחלנו |
| 5 קריאייטיבים | מחר / מחר ב-HH / היום / עוד שעה / התחלנו, 1:1 ו-9:16, ממותגים |
| פרסומי השקה | פייסבוק, לינקדאין, סטורי |
| זום | נוצר ב-API אם יש, אחרת הוראות בממשק |
| לוח שילוח | כל הודעה עם התאריך והשעה המדויקים, מוכנה להעתקה |
| ניתוח אחרי | נרשמו / הגיעו / המירו / מה לשפר |

הכל נשמר ב-`outputs/webinars/<slug>/` בפרויקט שלך. שכבת מכירות (סקר מועמדות + טאב מכירות) קיימת כנספח אופציונלי.

## התקנה ב-3 צעדים

1. מורידים את הזיפ ופותחים אותו (מקבלים תיקייה `webinar-os`).
2. פותחים Claude Code בתיקיית הפרויקט שבה רוצים לעבוד (כל תיקייה. אין פרויקט? יוצרים תיקייה ריקה בשם `webinars`).
3. מדביקים ל-Claude את הפרומפט הזה, עם הנתיב לתיקייה שפתחת:

```
התקן/י את הסקיל webinar-os מהתיקייה <הנתיב לתיקייה webinar-os שפתחתי> לפי הקובץ INSTALL.md שבתוכה. בסוף אמור/י לי שהכל תקין ומה הפקודה להפעלה.
```

Claude מעתיק/ה את הסקיל ל-`.claude/skills/webinar-os/` בפרויקט, מאמת/ת, ומחזיר/ה "מוכן". מאז: `/webinar-os` בכל שיחה.

## האם זה יעבוד אצלי?

| יש לי | מה קורה |
|-------|---------|
| Claude Code בלבד, שום חיבור | **כן, זה המסלול הבסיסי.** דפים + מצגת + טקסטים + קריאייטיבים כקבצים, Google Form ללידים, הוראות לכל השאר (בערך 20 דקות ידניות בסך הכל) |
| Claude Code + Python 3.9 ומעלה | כנ"ל, בלי תלות: הסקריפט משתמש בספרייה הסטנדרטית בלבד. Windows / Mac / Linux |
| Claude Code + Playwright / Chrome | הקריאייטיבים וצילומי המסך למצגת מצולמים אוטומטית |
| API לוואטסאפ (Green API וכדומה) | הקבוצה נוצרת ו-4 ההודעות נשלחות מתוזמנות לבד |
| Zoom API / MCP | הפגישה נוצרת לבד עם הלינק בקונפיג |
| מערכת דיוור עם MCP / API | הרשימה והמיילים המתוזמנים נוצרים לבד |
| Netlify / Cloudflare CLI | הדפים עולים לאוויר מהטרמינל |
| Claude.ai / ChatGPT בלי Claude Code | best-effort בלבד: 15 הפרומפטים ב-`reference/other-tools.md`, הבנייה ידנית |

מה שלא מחובר לא עוצר את הריצה. Claude אומר/ת בפירוש ליד כל רכיב: אוטומטי או ידני, ומה נשאר לך לעשות.

## כללים שהסקיל לא מוותר עליהם

- עברית, פנייה דו-מגדרית, בלי קו מפריד ארוך.
- אף נתון בלי מקור. אף פריסה מזויפת: כלי לא מחובר = מסלול ידני, ואומרים את זה.
- בדיוק 2 עצירות אישור. כל השאר אוטומטי.
- כל טופס לידים עם תיבת הסכמה אחת (מדיניות פרטיות + תנאי שימוש + עדכונים), חובה לסימון. צריך כתובת מדיניות פרטיות לפני שעולים לאוויר.
