# שלב 5 - 15 הרכיבים: מסלול אוטומטי ומסלול ידני

**מתי לטעון אותי:** בתחילת שלב 5 (אחרי אישור הקריאייטיבים). עוברים על הטבלה לפי הסדר; `config.integrations` קובע לכל שורה איזה מסלול.

## תוכן עניינים
1. סדר הבנייה
2. טבלת 15 הרכיבים

4. נספח: שכבת מכירות (אופציונלי)

## 1. סדר הבנייה

הסדר לא שרירותי: כל רכיב מזין את הבא.

1. קבוצת וואטסאפ → 2. לינק מקוצר לקבוצה → 3. זום/שידור → 4. לכידת לידים → 5. דפים (רינדור + פריסה) → 6. מיילים ווואטסאפ (תזמון או לוח שילוח) → 7. פרסומי השקה → 8. בדיקת זר/ה → 9. עדכון הקונפיג.

אם הקופי כבר אושר לפני שהיה לינק לקבוצה, אחרי שלב 2 מחליפים את `{{GROUP_LINK}}` ו-`{{BROADCAST_LINK}}` ב-copy.json בלינקים האמיתיים. לא כותבים קופי מחדש.

## 3. כללים חוצי-רכיבים

- **דיווח מסלול.** בסיום, ליד כל רכיב: "אוטומטי" או "ידני (מה נשאר לך לעשות: ...)". אין שורה בלי מסלול.
- **לא מזייפים.** אם API החזיר שגיאה, הרכיב עובר למסלול הידני ואומרים את זה בפירוש. לא "בערך עבד".
- **הסכמה.** כל טופס לידים כולל את `consent-block.html` (תיבה אחת, חובה). ב-Google Form, מוסיפים שאלת תיבת סימון חובה עם אותו נוסח.
- **לינקים ציבוריים** תמיד דרך הלינק המקוצר אם קיים (אפשר להחליף יעד בלי לשנות פרסומים).
- **בדיקת זר/ה** לפני "מוכן": הרשמה עם מייל בדיקה → שורה בגיליון/מערכת → דף תודה → כפתור לקבוצה. מוחקים את הבדיקה אחר כך.
- **שעות ישראל.** כל תזמון ב-`Asia/Jerusalem`. שעון קיץ נכנס לחישוב אוטומטית כשמשתמשים ב-`event_iso` עם אזור זמן.

## 4. נספח: שכבת מכירות (אופציונלי)

רק כש-`cta_goal` הוא `sell-product` או `book-call`, או שהמשתמש/ת ביקש/ה בפירוש. שני רכיבים נוספים:

| # | רכיב | מסלול אוטומטי | מסלול ידני |
|---|------|---------------|------------|
| 16 | סקר מועמדות | טופס במערכת הדיוור / webhook → טבלת מכירות | Google Form נפרד, 8-11 שאלות, מקושר מדף התודה ומהמייל האחרון |
| 17 | טאב מכירות | גיליון עם שורה לכל נרשם/ת + עמודת סטטוס (חדש / נוצר קשר / שיחה / נסגר / לא רלוונטי) | אותו גיליון, מתמלא ידנית |

שאלות מומלצות לסקר המועמדות: שם, טלפון, תחום העסק, ותק, מחזור חודשי (טווחים), האתגר המרכזי, מה ניסית עד היום, כמה זמן פנוי בשבוע, תקציב (טווחים), מתי נוח לשיחה, "מה יגרום לך להגיד כן".

הוספת סקר מזיזה את ה-CTA של דף התודה: הכפתור הראשי נשאר הקבוצה, וכפתור משני "מלא/י את השאלון" מתחתיו.
