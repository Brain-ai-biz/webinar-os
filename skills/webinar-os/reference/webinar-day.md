## 1. הקמת וובינר בזום

**וובינר, לא פגישה.** בוובינר הקהל לא רואה אחד את השני, לא יכול לפתוח מיקרופון, ואין "מסך של 100 ריבועים". בפגישה מעל 100 איש זה כאוס. Zoom Webinars דורש תוסף בתשלום (מ-Zoom Pro ומעלה). אין תקציב? Zoom Meeting עד 100 (חינם) או 300 (Pro), עם ההגדרות בסעיף "פגישה" בסוף.

**אזהרה: זום חינמי מנתק פגישה אחרי 40 דקות.** ברירת המחדל של הערכה היא וובינר של 60 דקות (`duration_min`), כלומר השידור ייקטע באמצע המצגת. לוובינר של 60 דקות צריך Zoom Pro (או לקצר את הוובינר ל-35 דקות ולעדכן את `duration_min`, את התסריט ואת המצגת בהתאם). חלופה חינמית בלי המגבלה הזאת: Google Meet (60 דקות, עד 100 משתתפים/ות) או YouTube Live. מאמתים את זה מול התשובה לשאלה 4 בראיון (פלטפורמת השידור) לפני שמחליפים את `{{BROADCAST_LINK}}`.

1. נכנסים ל-zoom.us → Webinars → Schedule a Webinar.
2. נושא (Topic): `<project_name>`. מועד (When): `date_iso` `time`, Duration: `duration_min` + 15. Time zone: Jerusalem.
3. הרשמה (Registration): **לא** מסומן (הנרשמים כבר אצלך; לינק אחד לכולם).
4. קוד (Webinar passcode): מסומן (הלינק כולל אותו). Waiting room: **לא**. Practice session: **כן** (נכנסים 20 דקות לפני ובודקים בלי שהקהל רואה).
5. וידאו (Video): Host on, Panelists on. Audio: both. **Q&A: on**, allow anonymous questions. Chat: on, לכולם.
6. אפשרויות (Webinar Options): **Record automatically → In the cloud**. Enable "Allow panelists to start video".
7. שומרים (Save) → Copy Invitation → מעתיקים **רק** את הלינק (Join URL עם `pwd` בתוכו). זה `config.broadcast_link`. מחליפים `{{BROADCAST_LINK}}` ב-`emails.md`, `whatsapp.md`, `schedule.md`.

**אם פגישה (Meeting):** Schedule a Meeting → Passcode מסומן, Waiting Room לא, "Mute participants upon entry" כן, "Allow participants to unmute themselves" **לא**, Screen share: Host only, Record to cloud.

## 4. `after.md`: מה סופרים ומה משפרים

מיד אחרי (עד 24 שעות), ממלאים:

```markdown
# אחרי · <project_name> · <date_he>

| מדד | מספר | מאיפה |
|---|---|---|
| נרשמו | | הגיליון (או ספירת הקבוצה) |
| הצטרפו לקבוצה | | ספירת חברים בקבוצה |
| הגיעו לשידור | | Zoom → Reports → Webinar → Attendees (Unique) |
| נשארו עד הסוף | | אותו דוח, עמודת Duration ≥ 80% מהאורך |
| אחוז הגעה | הגיעו ÷ נרשמו | מקובל לוובינר חינמי: 30-45% |
| אחוז הישארות | נשארו ÷ הגיעו | טוב: 60%+ |

## 3 דברים לשפר בפעם הבאה
1. איפה הדליפה הכי גדולה (הרשמה → קבוצה / קבוצה → הגעה / הגעה → סוף), ומה הכי זול לתקן.
2. שאלה שחזרה בצ'אט ולא הייתה במצגת.
3. שקף שבו איבדנו אנשים (לפי הזמן ביציאות בדוח הזום).

## מה נשלח אחרי
מייל / הודעה עם ההקלטה (אם הובטחה) והצעד הבא, עד 24 שעות.
```

**מצב כפתור לקבוצה** (`form_action` ריק): אין גיליון, הקבוצה היא הרשימה, ולכן "נרשמו" ו"הצטרפו לקבוצה" הם אותו מספר. מאחדים את שתי השורות הראשונות לשורה אחת ומורידים את הדליפה "הרשמה → קבוצה" (היא לא קיימת במצב הזה):

```markdown
| הצטרפו לקבוצה (= נרשמו) | | ספירת חברים בקבוצה |
| הגיעו לשידור | | Zoom → Reports → Webinar → Attendees (Unique) |
| נשארו עד הסוף | | אותו דוח, עמודת Duration ≥ 80% מהאורך |
| אחוז הגעה | הגיעו ÷ הצטרפו לקבוצה | מקובל לוובינר חינמי: 30-45% |
| אחוז הישארות | נשארו ÷ הגיעו | טוב: 60%+ |
```
שורת השיפור הראשונה במצב הזה: "איפה הדליפה הכי גדולה (קבוצה → הגעה / הגעה → סוף), ומה הכי זול לתקן."
