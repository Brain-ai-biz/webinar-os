# שלב 0.5 - ראיון התאמה: מה מחובר אצלך

**מתי לטעון אותי:** אחרי 8 שאלות התוכן (שלב 0), לפני המחקר. פעם אחת לריצה. התוצאה נשמרת ב-`config.integrations`.

## למה זה קיים

הסקיל עובד אצל כולם, אבל לא אצל כולם באותה צורה. מי שיש לו/ה API לוואטסאפ מקבל/ת קבוצה שנוצרת לבד; מי שאין, מקבל/ת הוראות של 2 דקות. הראיון הזה קובע פעם אחת לכל רכיב מה המסלול, ומאז לא שואלים שוב.

## לפני ששואלים: בודקים לבד (30 שניות)

לא שואלים על מה שאפשר לגלות. בודקים בשקט:

1. **MCP מחוברים** בסשן (זום? Google Drive? Canva? מערכת דיוור?).
2. **`.env` בפרויקט**: מפתחות עם שמות כמו `GREEN_API`, `ZOOM_`, `BITLY_`, `DUB_`, `CLOUDFLARE_`, `NETLIFY_`, `OPENAI_`.
3. **`composio` בטרמינל** (`composio --version`): אם קיים, `composio connections` מראה מה מחובר.
4. **סקריפטים קיימים** ב-`scripts/` עם שמות שמרמזים על שליחת וואטסאפ / מייל / קיצור לינקים.

מה שנמצא מוצג כברירת מחדל בשאלה המתאימה ("ראיתי שיש לך Zoom API ב-.env, להשתמש בו?").

## 6 השאלות (AskUserQuestion, 2 קריאות של 3)

### 1. איפה הדפים יעלו לאוויר? (→ `integrations.hosting`)

| תשובה | ערך | מסלול |
|-------|-----|-------|
| "אין לי מושג" / "הכי פשוט" | `netlify-drop` | ידני: גוררים תיקייה לדפדפן, מקבלים לינק תוך דקה |
| Cloudflare Pages / Netlify עם CLI מחובר | `cloudflare-pages` / `netlify` | אוטומטי: פריסה מהטרמינל |

### 6. תמונות ומצגות: איזה כלי? (→ `integrations.images`, `integrations.slides`)

## שאלה 7 (נגזרת, לא שואלים): לכידת לידים (→ `integrations.capture`)

נקבע אוטומטית:
- מערכת דיוור מחוברת עם endpoint/טופס → `mailing-form` (`form_action` = כתובת הטופס של המערכת).
- יש Make / Zapier / n8n / Worker עם webhook → `endpoint` (`capture_endpoint` = ה-URL, מקבל JSON).
- כלום → `google-form` (ברירת המחדל שעובדת תמיד; הוראות ב-`manual-paths.md`).
- המשתמש/ת מבקש/ת בפירוש "בלי טופס, רק קבוצה" → `button-only` (הדף מציג כפתור הצטרפות לקבוצה במקום טופס).

## מה כותבים לקונפיג

```json
"integrations": {
  "hosting": "netlify-drop",
  "mailing": "רב מסר",
  "mailing_auto": false,
  "whatsapp": "manual",
  "video": "zoom",
  "shortener": "bitly",
  "images": "html-screenshot",
  "slides": "deck-basic",
  "capture": "google-form"
}
```

אחרי הכתיבה מציגים למשתמש/ת שורה אחת לכל רכיב: "דפים: Netlify Drop (ידני) · דיוור: רב מסר (ידני) · וואטסאפ: מהטלפון (ידני) · ...". זו התוכנית. אין הפתעות בשלב 5.
