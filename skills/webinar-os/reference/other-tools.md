# נספח: 7 הפרומפטים לכלים אחרים (Claude.ai / ChatGPT / Gemini), בלי אחריות

**מתי לטעון אותי:** רק כשמישהו/י בלי Claude Code מבקש/ת את השיטה.

**בלי אחריות.** Claude Code הוא המסלול הנתמך: הוא קורא קבצים, מריץ את `render_pages.py`, שומר מצב בין שלבים. בצ'אט רגיל אין קבצים, אין סקריפטים ואין זיכרון. הפרומפטים נותנים את התוכן; את הדפים בונים ידנית (למשל ב-Canva / מערכת הדיוור), לפי אותם 8 סקשנים.

## תוכן עניינים
1. איך משתמשים
2. פרומפט 0 · הקשר
3. פרומפטים 1-7 · אחד לכל שלב

## 1. איך משתמשים
פותחים שיחה חדשה, מדביקים את פרומפט 0 ועונים. שומרים את התשובה. בכל פרומפט הבא מדביקים אותה בראש.

## 2. פרומפט 0 · הקשר
```
אני מפיק/ה וובינר חי. תשאל/י אותי 8 שאלות, אחת-אחת: על מה הוובינר; מה יוצאים איתו ביד בסוף השעה; למי (אדם אחד: מה עושה, מה מציק); תאריך, שעה, אורך, פלטפורמה, יש הקלטה; מי מעביר/ה + ההוכחה הכי חזקה; מה קורה אחרי ההרשמה (ברירת מחדל: קבוצת וואטסאפ); שם קצר באנגלית; לינק למדיניות פרטיות. ואז 3 שאלות קול: איך אני מדבר/ת עם הקהל (ישיר / חם / מקצועי / אנרגטי), לשון פנייה (את/ה / אתם/ן / בואו), מילים אסורות. בסוף החזר/י סיכום אחד של כל התשובות.
כללים לכל מה שתכתוב/י מעכשיו: עברית, פנייה דו-מגדרית (יחיד/ה קודם), בלי קו מפריד ארוך, בלי מספרים בלי מקור.
```

## 3. פרומפטים 1-7

**1 · מחקר**
```
[הקשר] מצא/י 6-10 עובדות מאומתות על הנושא ממקורות מהימנים. לכל אחת: המשפט, המספר, המקור, השנה, לינק, ראשוני/משני. אין לך גישה לרשת? אמור/י את זה ואל תמציא/י. סמן/י 3 עובדות שמתאימות לשקפי מספר.
```
**2 · מצגת ותסריט**
```
[הקשר + מחקר] בנה/י מצגת של 30-40 שקפים ב-14 מערכות: פתיחה · למה עכשיו · מי אני · הבעיה · למה הדרך הרגילה נכשלת (3 שקפי מספר עם מקור) · הרעיון הגדול · הוכחה · עיקרון 1 · 2 · 3 · הדגמה (צילומי מסך, לא דמו חי) · סיכום · הצעד הבא · שאלות. לכל שקף: מספר, תבנית (title / section / bullets / three-columns / big-stat / quote / screenshot / cta), טקסט מינימלי, ומה אומרים (ספור/י מילים; 2.5 מילים לשנייה; יעד 6,700-7,500 מילים סך הכל).
```
**3 · דף הרשמה**
```
[הקשר + מחקר] כתוב/י קופי לדף הרשמה ב-8 סקשנים: מסך ראשון (שורת הקשר, כותרת 5-10 מילים כתוצאה עם 2-3 מילים מודגשות, תת-כותרת, כפתור אחד בקול הלקוח, שורת ביטחון) · הכאב (כותרת, 2 פסקאות של רגע ביום, משפט גשר) · מה תקבלו (4 פריטים: כותרת-תוצאה + משפט) · מי מעביר/ה (תפקיד, 3 שורות, הוכחה אחת) · למי זה (3 כן, 2 לא) · טופס (כותרת, משפט, שורה מתחת לכפתור) · 5 שאלות נפוצות · סוגר (התאריך במשפט). תן/י 3 חלופות לכותרת.
```
**4 · דף תודה**
```
[הקשר] כתוב/י דף תודה: כותרת, משפט, "הצעד הבא: קבוצת הוואטסאפ" (כותרת, משפט, כפתור), 3 צעדים קצרים, ומשפט שיתוף לוואטסאפ.
```
**5 · קבוצת וואטסאפ**
```
[הקשר] כתוב/י: שם לקבוצה, הודעת פתיחה מוצמדת (עד 5 שורות: מה, מתי, שהלינק יישלח כאן שעה לפני, איך שואלים), תיאור קבוצה עד 2 שורות, והוראות של 5 צעדים לפתיחת קבוצה שקטה (רק מנהלים שולחים) עם לינק הזמנה.
```
**6 · תזכורות**
```
[הקשר + לינק קבוצה] כתוב/י 3 מיילים (ברוכים הבאים מיד; "מחר ב-X" יום לפני; "עוד שעה") עם נושא עד 45 תווים, גוף 80-160 מילים, לינק אחד; ו-4 הודעות וואטסאפ (מחר / היום / עוד שעה / התחלנו עם {{BROADCAST_LINK}}), 2-4 שורות, לינק בשורה משלו. ואז לוח שילוח: תאריך ושעה מדויקים לכל אחת (מיד / יום לפני 10:00 / יום האירוע 10:00 / שעה לפני / בשעה).
```
**7 · הוובינר**
```
[הקשר] תן/י: הוראות הקמת וובינר בזום (וובינר לא פגישה, הקלטה לענן, בלי חדר המתנה, practice session), צ'קליסט 10 דקות לפני, ותבנית "אחרי": נרשמו / הגיעו / נשארו / אחוזים, ו-3 שורות "מה לשפר".
```
