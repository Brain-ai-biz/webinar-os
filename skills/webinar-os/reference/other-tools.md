# נספח: 15 הפרומפטים לכלים אחרים (Claude.ai / ChatGPT / Gemini)

**מתי לטעון אותי:** רק כשמישהו/י בלי Claude Code מבקש/ת את השיטה. או כשמעבירים חלק מהעבודה (למשל המצגת) לכלי צ'אט אחר.

**בלי אחריות.** Claude Code הוא המסלול הנתמך: הוא קורא את הקונפיג, מריץ את `render_pages.py`, מצלם, ופורס. בצ'אט רגיל אין קבצים, אין סקריפטים ואין זיכרון בין שיחות. הפרומפטים כאן נותנים את התוכן; את הבנייה עושים ביד לפי `manual-paths.md`.

## תוכן עניינים
1. איך משתמשים
2. פרומפט 0 · קונפיג
3. פרומפטים 1-7 · מחקר, קופי, מיילים, וואטסאפ, קריאייטיבים, פוסטים
4. פרומפטים 8-9 · מצגת ותסריט
5. פרומפטים 10-12 · לוח שילוח, Google Form, קבוצה
6. פרומפטים 13-15 · שאלות ותשובות, מייל הקלטה, ניתוח

## איך משתמשים

1. פותחים שיחה חדשה ומדביקים את **פרומפט 0** (ההקשר). שומרים את התשובה: זה הקונפיג.
2. בכל פרומפט הבא מדביקים את הקונפיג בראש, ואז את הפרומפט.
3. את התוצרים שומרים כקבצים ידנית (`copy.json`, `deck-outline.md` וכו').

## פרומפט 0 · קונפיג

```
אני מפיק/ה וובינר חי. תשאל/י אותי 8 שאלות, אחת-אחת: נושא, הזווית הרגשית (הצע/י 3), תאריך ושעה, מה מוכרים בקצה (או כלום), קהל היעד, מטרת המשפך (הגעה / מכירה / שיחה), שם קצר באנגלית, ומיתוג (שם, צבע, פונט). בסוף החזר/י JSON אחד עם כל התשובות, בשמות השדות: slug, project_name, topic, angle, big_idea, audience, date_he, time, event_iso, host, cta_goal, offer, brand_name, brand.
כללים לכל מה שתכתוב/י מעכשיו: עברית, פנייה דו-מגדרית (יחיד/ה קודם, כמו "בעל/ת עסק"), בלי קו מפריד ארוך, בלי הבטחות מספריות בלי מקור.
```

## פרומפט 1 · מחקר

```
[קונפיג]
מצא/י 6-10 נתונים מאומתים על הנושא הזה ממקורות מהימנים (מחקרים, דוחות של חברות ייעוץ, כתבות מקור). לכל נתון: הטענה, המספר, המקור, השנה, לינק, ורמת ביטחון (ראשוני / משני). נתון בלי מקור לא נכנס. סיים/י ב-3 זוויות רגשיות שהנתונים תומכים בהן.
```

## פרומפט 2 · קופי דף הרשמה

```
[קונפיג + מחקר]
כתוב/י את הקופי לדף הרשמה לוובינר, בקול שלי ([3 מילים על הטון]). מבנה: שורה רצה (עד 12 מילים) · תג · כותרת הוק עד 8 מילים (הזווית, לא הנושא) · תת-כותרת עד 25 · CTA אחד עד 5 מילים · פסקת כאב (3 פסקאות קצרות) · הרעיון הגדול (כותרת, משפט מוביל, 4 יתרונות) · מה יהיה בשידור (4-5 בולטים) · גשר להצעה (2-3 משפטים, בלי הבטחה אם אין מוצר) · טופס (כותרת, משפט, תוויות, כפתור, שורת פרטיות).
```

## פרומפט 3 · דף תודה

```
[קונפיג]
כתוב/י דף תודה קצר: תג "נרשמת בהצלחה", כותרת, 2 משפטים שאומרים שהלינק לשידור יישלח בקבוצת הוואטסאפ ושכדאי להיכנס עכשיו, כפתור "להצטרפות לקבוצת הוואטסאפ", 3 צעדים, ושורת "שמרו ביומן".
```

## פרומפט 4 · 3 מיילים

```
[קונפיג + לינק קבוצה]
כתוב/י 3 מיילים לנרשמים: (1) ברוכים הבאים, נשלח מיד: אישור, מה יהיה, הזמנה לקבוצה. (2) "מחר בשעה X", יום לפני: תזכורת + חימום הזווית בלי לחשוף. (3) "עוד שעה": קצר, דחוף, לינק ומשפט הוק אחד. לכל מייל: נושא עד 45 תווים, טקסט פתיחה עד 60, גוף 80-160 מילים, לינק אחד, חתימה בשם פרטי.
```

## פרומפט 5 · 4 הודעות וואטסאפ

```
[קונפיג]
כתוב/י 4 הודעות וואטסאפ לקבוצת הוובינר: "מחר" (יום לפני 10:00), "היום" (בוקר האירוע), "עוד שעה", "התחלנו" (עם המילה {{BROADCAST_LINK}} במקום הלינק). כל הודעה 2-4 שורות, השורה הראשונה היא ההודעה כולה, אימוג'י אחד לכל היותר בשורה, לינק בסוף בשורה משלו.
```

## פרומפט 6 · 5 קריאייטיבים

```
[קונפיג]
כתוב/י טקסט ל-5 קריאייטיבים: מחר / מחר ב-HH:MM / היום ב-HH:MM / עוד שעה / התחלנו. לכל אחד: שורת פאנץ' עד 4 מילים ושורת משנה עד 8. ואז תאר/י עיצוב אחד שמתאים לכולם (רקע, צבע הדגשה, מיקום הטקסט, לוגו) כדי שאבנה אותם ב-Canva.
```

## פרומפט 7 · פרסומי השקה

```
[קונפיג + לינק מקוצר]
כתוב/י 3 פוסטים להשקת ההרשמה: פייסבוק (עד 120 מילים, שאלה פותחת), לינקדאין (עד 150 מילים, זווית מקצועית), וסטורי (3 מסכים, עד 12 מילים כל אחד). כולם עם אותו CTA ואותו לינק.
```

## פרומפט 8 · מבנה המצגת

```
[קונפיג + מחקר]
בנה/י מצגת של כ-40 שקפים ב-14 מערכות: פתיחה · למה עכשיו · מי אני · הבעיה · למה הפתרונות הרגילים נכשלים (עם הנתונים) · הרעיון הגדול · הוכחה · עיקרון 1 · עיקרון 2 · עיקרון 3 · הדגמה (צילומי מסך, לא דמו חי) · סיכום · גשר להצעה · שאלות + CTA. לכל שקף: מספר, מערכה, תבנית (title / big-stat / three-columns / bullets / quote / screenshot / section / cta), כותרת, טקסט (מינימלי), ויזואל, הערת דובר של 2-3 משפטים.
```

## פרומפט 9 · תסריט הגשה

```
[מבנה המצגת]
כתוב/י תסריט הגשה מלא: לכל שקף מה אומרים (2-6 משפטים), משפטי מעבר, ו-[עצירה] לשאלה לקהל כל 5-7 שקפים. קצב 2.5 מילים לשנייה; סך הכל 5,000-6,000 מילים לשעה כולל שאלות ותשובות.
```

## פרומפט 10 · לוח שילוח

```
[קונפיג + כל הטקסטים]
הפק/י לוח שילוח: לכל הודעה (3 מיילים, 4 וואטסאפים, 5 קריאייטיבים) תאריך ושעה מדויקים לפי תאריך האירוע: מיד עם ההרשמה / יום לפני 10:00 / יום האירוע 10:00 / שעה לפני / בשעת השידור. פורמט: כותרת, מתי, הטקסט המלא מוכן להעתקה. בסוף: 4 תזכורות ליומן.
```

## פרומפט 11 · הוראות Google Form

```
תן/י לי הוראות של 5 צעדים ליצירת Google Form עם שם, אימייל, טלפון ותיבת הסכמה אחת חובה ("קראתי ואני מאשר/ת את מדיניות הפרטיות ותנאי השימוש, ומעוניין/ת לקבל עדכונים"), עם גיליון תשובות, והודעת אישור שמפנה לקבוצת הוואטסאפ [לינק].
```

## פרומפט 12 · הודעת פתיחה לקבוצה + תיאור

```
[קונפיג]
כתוב/י הודעת פתיחה מוצמדת לקבוצת הוואטסאפ של הוובינר (עד 5 שורות: מה, מתי, שהלינק יישלח כאן שעה לפני, איך שואלים שאלות) ותיאור קבוצה עד 2 שורות.
```

## פרומפט 13 · שאלות ותשובות צפויות

```
[קונפיג + מבנה המצגת]
כתוב/י 12 שאלות שהקהל צפוי לשאול בסוף הוובינר, עם תשובה של 2-3 משפטים לכל אחת, כולל 3 שאלות "קשות" (מחיר, "זה לא יעבוד אצלי", פרטיות).
```

## פרומפט 14 · מייל ההקלטה (יום אחרי)

```
[קונפיג]
כתוב/י מייל ליום שאחרי לכל הנרשמים: תודה למי שהגיע/ה, לינק להקלטה [לינק], 3 נקודות מרכזיות מהשידור, והצעד הבא (לפי מטרת המשפך). עד 150 מילים.
```
