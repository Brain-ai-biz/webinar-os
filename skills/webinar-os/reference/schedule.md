# שלב 5 - לוח השילוח

**מתי לטעון אותי:** ברכיבים 11-12 (מיילים ווואטסאפ), אחרי שיש לינק קבוצה ולינק שידור. גם כשהשליחה אוטומטית, הקובץ נוצר לצורך מעקב.

## הלוח

`D` = יום האירוע, `T` = שעת השידור (`config.time`). כל השעות ב-Asia/Jerusalem.

| מתי | ערוץ | הודעה | לינק בהודעה |
|-----|------|-------|-------------|
| מיד עם ההרשמה | מייל | `emails[welcome]` | קבוצה |
| מיד עם ההצטרפות לקבוצה | וואטסאפ (בקבוצה) | הודעת פתיחה: מה זה, מתי, שהלינק יישלח כאן | אין |
| D-1 בשעה 10:00 | מייל | `emails[day_before]` | קבוצה |
| D-1 בשעה 10:00 | וואטסאפ | `whatsapp[tomorrow]` | קבוצה (לשיתוף) |
| D בשעה 10:00 | וואטסאפ | `whatsapp[today]` | אין ("הלינק יישלח שעה לפני") |
| D בשעה T-1h | מייל | `emails[one_hour_before]` | שידור |
| D בשעה T-1h | וואטסאפ | `whatsapp[one_hour]` | שידור |
| D בשעה T | וואטסאפ | `whatsapp[live]` | שידור |

קריאייטיבים לרשתות (רשות, לפי אותו קצב): D-1 בוקר `tomorrow`, D-1 ערב `tomorrow_time`, D בוקר `today`, D בשעה T-1h `one_hour`, D בשעה T `live`.

למה 10:00: שעת הפתיחה הגבוהה ביותר בוואטסאפ ובמייל לקהל עסקי בישראל לפני שהיום מתמלא. אם השידור בבוקר (לפני 12:00), מזיזים את "היום 10:00" ל-T-3h.

## מסלול אוטומטי

- **מייל**: מערכת הדיוור מחוברת → welcome כסדרה "בהצטרפות לרשימה"; day_before + one_hour_before כדיוורים מתוזמנים לרשימת הוובינר. מאמתים שהתזמון הוא בשעון ישראל.
- **וואטסאפ**: API → 4 משימות מתוזמנות (cron / launchd / Task Scheduler / שירות המשימות של ה-API). כל אחת שולחת לכל הקבוצות ב-`config.groups`. `{{BROADCAST_LINK}}` מוחלף בזמן השליחה.
- אחרי ההתקנה: מציגים למשתמש/ת את הלוח עם "מתוזמן ✅" ליד כל שורה, ומה קורה אם המחשב כבוי (cron מקומי לא רץ; להעדיף את תזמון השירות).

## מסלול ידני: קובץ `schedule.md`

נוצר ב-`outputs/webinars/<slug>/schedule.md` בפורמט הזה, מוכן להעתקה בלחיצה:

```markdown
# לוח שילוח · <project_name> · <date_he> <time>

## ✉️ 1. מייל ברוכים הבאים · שליחה: אוטומטית עם ההרשמה (או פעם ביום למצטרפים חדשים)
**נושא:** ...
**טקסט פתיחה:** ...

(גוף המייל, מוכן להעתקה)

## 💬 2. וואטסאפ "מחר" · שליחה: <תאריך D-1> בשעה 10:00
(טקסט ההודעה, מוכן להעתקה)

## ✉️ 3. מייל "מחר" · שליחה: <תאריך D-1> בשעה 10:00
...

(וכן הלאה עד ההודעה השמינית)

## תזכורות ליומן
- <תאריך D-1> 09:50: לשלוח מייל + וואטסאפ "מחר"
- <תאריך D> 09:50: לשלוח וואטסאפ "היום"
- <תאריך D> <T-1h פחות 10 דק'>: לשלוח מייל + וואטסאפ "עוד שעה"
- <תאריך D> <T>: לפתוח את השידור, לשלוח "התחלנו"
```

התאריכים מחושבים מ-`date_iso` ו-`time` בפועל (לא "D-1" בקובץ הסופי). אם יש חיבור ליומן (Google Calendar MCP / Composio), מוסיפים את 4 התזכורות ליומן של המשתמש/ת אוטומטית.

## שליחה ידנית: 3 טיפים

1. **מייל**: במערכת הדיוור, מתזמנים את שלושת המיילים מראש ביום שהדף עולה. ב-Gmail: "Schedule send" (החץ ליד שלח). BCC לרשימת הנרשמים מהגיליון, לא TO.
2. **וואטסאפ**: מכינים את 4 ההודעות ב"פתקים" בטלפון, ומעתיקים בזמן. הודעה בקבוצה שקטה (רק מנהלים כותבים) כדי שלא תיבלע.
3. **לינק השידור**: נשלח רק בשעה לפני ובשעת השידור, לא קודם. ככה הקבוצה נשארת רלוונטית והלינק לא מסתובב.
