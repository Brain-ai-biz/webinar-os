# מערכת העיצוב של Webinar-OS

**מתי לטעון אותי:** כשרוצים להבין למה הדפים, המצגת והקריאייטיב נראים אותו דבר, או כשרוצים למתג (מסלול מתקדם). בזרימת הבסיס לא נוגעים בכלום: הכל כבר מוגדר.

## תוכן עניינים
1. העיקרון
2. בלוק הטוקנים (8 שורות)
3. הדקדוק הוויזואלי
4. איך ממתגים (8 שורות, פעם אחת)
5. ניגודיות ונגישות
6. פונט: Heebo ומה קורה בלי אינטרנט

## 1. העיקרון

ארבעה קבצים (`landing.html`, `thank-you.html`, `deck-basic.html`, `creative.html`) חולקים **בלוק `:root` אחד זהה** ו**אותו דקדוק ויזואלי**: אותם מרווחים, אותו כרטיס, אותו כפתור, אותה גלולה, אותו מספר-ענק, אותו קו מפריד. לכן דף ההרשמה, המצגת והקריאייטיב מרגישים כמו מוצר אחד, אצל כל משתמש/ת, בלי מעצב/ת.

ברירת המחדל: כהה (נייבי כמעט שחור), צבע הדגשה חם אחד, ניגודיות גבוהה. בלי תמונות חובה. זה נראה פרימיום גם עם טקסט בלבד.

## 2. בלוק הטוקנים (8 שורות)

מופיע מילה במילה בראש ה-CSS של כל ארבעת הקבצים. `render_pages.py` ממלא אותו מ-`DEFAULT_BRAND` (ואם יש `config.brand`, מהערכים שם).

```css
:root{
  --bg:#0A0E1A;        /* רקע הדף / השקף: נייבי כמעט שחור */
  --surface:#131A2C;   /* משטח: כרטיסים, שדות, טופס */
  --ink:#F4F6FB;       /* טקסט ראשי */
  --muted:#9BA6C0;     /* טקסט משני */
  --accent:#F5B54A;    /* צבע ההדגשה: כפתור, מספרים, kicker */
  --accent-2:#FF7A59;  /* הקצה השני של הגרדיאנט */
  --radius:18px;       /* עיגול פינות של כרטיסים וטפסים */
  --font:'Heebo',system-ui,-apple-system,'Segoe UI',Arial,sans-serif;
}
```

מתחת לבלוק יש "נגזרות" (`--line`, `--glow`, `--grid`, `--grad`, `--on-accent`, סקאלת מרווחים `--s1..--s6` = 8/16/24/40/64/96). הן מחושבות מהטוקנים ולא נוגעים בהן.

## 3. הדקדוק הוויזואלי

| אלמנט | class | איך הוא נראה, בכל הקבצים |
|---|---|---|
| סצנה | `.scene` / `.slide::before` | גריד עדין (64-80px) שדוהה במסכה + זוהר רך בצבע ההדגשה בפינה העליונה |
| גלולה (eyebrow) | `.eyebrow` | מסגרת דקה בצבע ההדגשה, רקע 8%, נקודה זוהרת בהתחלה. שורת ההקשר במסך הראשון, התג במצגת ובקריאייטיב |
| kicker | `.kicker` | אותיות קטנות מרווחות בצבע ההדגשה עם קו קצר לפני (ואחרי, במרכז) |
| כותרת עם מילה חמה | `.warm` | span עם גרדיאנט accent → accent-2 על הטקסט. מילה אחת או שתיים, לא כל הכותרת |
| כפתור | `.btn` | גלולה, גרדיאנט, טקסט כהה (`--on-accent`), חץ ←, צל זוהר. **כפתור אחד בעיצוב אחד** בכל הדף |
| כרטיס | `.card` | `--surface`, מסגרת 1px, מסגרת-גרדיאנט עדינה (35%), `--radius`. בריחוף: עולה 3px |
| מספר ענק | `.big-num` | 900 משקל, גרדיאנט, ספרות ברוחב קבוע. במצגת 320px, בדף עד 64px |
| קו מפריד | `.divider` | 1px שדוהה לקצוות (דף) / 4px גרדיאנט קצר (מצגת) |
| מספור | `.num` / `.icon` | ריבוע מעוגל בגרדיאנט עם מספר כהה |
| ספירה לאחור | `.countdown` | 3 תיבות `--surface`, מספרים 800 |

מרווחים: סקשן בדף = `clamp(64px, 9vw, 112px)`; שקף = ריפוד 120/150px; כרטיס = 26/24px (דף) או 56/48px (מצגת).

## 4. איך ממתגים (מסלול מתקדם)

**דרך א (מומלץ):** ב-`config.json` מוסיפים:
```json
"brand": { "bg": "#0B0F14", "surface": "#161B22", "ink": "#FFFFFF", "muted": "#9AA4B2",
           "accent": "#2DD4BF", "accent_2": "#60A5FA", "radius": "14px", "font": "Rubik", "logo": "logo.png" }
```
מריצים `render_pages.py` שוב. כל 4 הקבצים מתעדכנים ביחד, כולל שורת ה-`<link>` שטוענת את הפונט מ-Google Fonts (הסקריפט ממלא אותה מ-`font`, רווחים הופכים ל-`+` לבד). `font` חייב להיות פונט מ-Google Fonts עם עברית (Heebo, Rubik, Assistant, Noto Sans Hebrew, Frank Ruhl Libre); לא עורכים את ה-HTML ביד.

**דרך ב:** עורכים את 8 השורות ישירות בקובץ שנוצר. עובד, אבל ריצה חוזרת של `render_pages.py` דורסת.

כללים: צבע הדגשה אחד. אם הרקע בהיר, מחליפים גם `--on-accent` (בנגזרות) לטקסט בהיר על הכפתור ובודקים ניגודיות מחדש.

## 5. ניגודיות ונגישות

ברירת המחדל עוברת WCAG AA: `--ink` על `--bg` 17:1, `--muted` על `--bg` 7.8:1, `--on-accent` על `--accent` 11:1. שינוי צבע = בדיקה מחדש (למשל webaim.org/resources/contrastchecker). בכל הקבצים: `lang="he" dir="rtl"`, פוקוס נראה, `prefers-reduced-motion` מכבה אנימציות, `skip link`.

## 6. פונט: Heebo ומה קורה בלי אינטרנט

הפונט Heebo נטען מ-Google Fonts (חינם, עברית מלאה, 5 משקלים). אין אינטרנט או חומת אש? הדפדפן נופל ל-`system-ui` / Arial: העימוד נשאר זהה (אותם גדלים, אותם מרווחים), רק צורת האותיות שונה. שום דבר לא נשבר ולא זז.
