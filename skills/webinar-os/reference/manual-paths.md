# הוראות של דקה-שתיים: Google Form, קבוצת וואטסאפ, פתיחת הדפים, העלאה לאוויר

**מתי לטעון אותי:** בשלבים 3-5, כשצריך לתת למשתמש/ת הוראות ידניות. נותנים רק את הסעיף הרלוונטי, לא את כל הקובץ. כל סעיף עובד לכולם, בלי מפתחות ובלי חיבורים.

## תוכן עניינים
1. לכידת לידים: Google Form מאחורי הטופס המעוצב (או "כפתור בלבד")
2. קבוצת וואטסאפ + לינק הזמנה (שלב 5)
3. לפתוח ולבדוק את הדפים במחשב
4. להעלות את הדפים לאוויר (שלב 9, ב-`publish.md`)
5. להוסיף ליומן

## 1. לכידת לידים

### מצב א (ברירת המחדל): הדף שלנו, Google Form מאחורי הקלעים
הדף נשאר מעוצב; הנרשמים נוחתים בגיליון.

1. **הטופס**: forms.google.com → טופס ריק → שם: "<project_name> - נרשמים". 3 שאלות "תשובה קצרה", חובה: שם פרטי, טלפון, אימייל. שאלה רביעית "תיבות סימון" עם אפשרות אחת: "קראתי ואני מאשר/ת את מדיניות הפרטיות ותנאי השימוש, ומעוניין/ת לקבל עדכונים" (חובה).
   **אזהרה, זו התקלה הכי שקטה שיש:** טקסט האפשרות בטופס חייב להיות זהה, אות באות, לטקסט שהדף שולח (הוא מגיע מ-`templates/consent-block.html`). מדדנו: טקסט שונה, או שאלת הסכמה "חובה" בלי `entry` בקונפיג, מחזירים 400 מגוגל, ואף הרשמה לא נשמרת. המבקר/ת לא רואה כלום, כי הדף מציג "תודה" בכל מקרה. שינית את הנוסח בטופס? מעדכנים גם את הבלוק בדף, או שמגדירים את השאלה כלא-חובה.
2. **הגיליון**: לשונית "תשובות" → אייקון Sheets → "צור גיליון אלקטרוני חדש". זה גיליון הנרשמים. (אין דרך לעשות את זה בקוד: זו הדרך היחידה, שתי הקלקות.)
   **פתיחת הטופס לכולם:** "שלח" → הגדרות שיתוף → "כל מי שיש לו את הקישור". חשבון ארגוני (Workspace) פותח טפסים כברירת מחדל רק לארגון, ואז אנשים מבחוץ נדחים בשקט. בודקים בדפדפן פרטי (בלי להיות מחוברים) שהטופס נפתח.
3. **כתובת השליחה**: "שלח" → אייקון לינק → מעתיקים. מחליפים בסוף `/viewform` ב-`/formResponse`. זה `form_action`.
4. **מזהי השדות**: בעורך הטופס, שלוש נקודות (⋮) למעלה → "קבלת קישור מלא מראש" → ממלאים תשובות דמה: שם = `שם`, טלפון = `050`, מייל = `a@b.c`, מסמנים את ההסכמה → "קבלת קישור" → "העתקת קישור". מדביקים את הקישור בצ'אט: "הנה הקישור המלא מראש". בקישור מופיע `entry.123456789=` לכל שדה, ואת המיפוי (שם, טלפון, מייל, הסכמה) Claude מחלץ לבד ומכניס לקונפיג. חלופה, רק אם הקישור לא זמין: תצוגה מקדימה (עין) → F12 → חיפוש `entry.` במקור הדף.
5. **לקונפיג**:
   ```json
   "form_action": "https://docs.google.com/forms/d/e/XXXX/formResponse",
   "form_fields": { "name": "entry.111", "phone": "entry.222", "email": "entry.333", "consent": "entry.444" }
   ```
   הדף שולח גם `utm_*`, `page` ו-`consent_ts`; גוגל מקבלת פרמטרים עודפים בלי בעיה, אז לא מוחקים אותם.
   בלי `consent` בגיליון? הדף לא שולח בלי סימון, אז כל מי שבגיליון אישר/ה; חותמת הזמן `consent_ts` נשמרת בשדה נסתר ונשלחת רק אם יש לה entry.
6. **בדיקה (עובדת גם מקומית, לפני ההעלאה)**: `render_pages.py` → פותחים `landing/index.html` במחשב → נרשמים עם מייל בדיקה → הדף עובר לדף התודה, והשורה מופיעה בגיליון תוך שניות (זו ההוכחה) → מוחקים אותה. אחרי ההעלאה (סעיף 4) חוזרים על אותה בדיקה פעם אחת על הלינק החי.

### עברת ממצב ב למצב א באמצע?
`copy.json` נכתב בזמנו לכפתור, אז `form.sub` ו-`form.after` עדיין מבטיחים "לחיצה אחת ונכנסים לקבוצה" מעל טופס בן שלושה שדות. כותבים את שתי השורות מחדש למצב טופס ("משאירים פרטים, והלינק לשידור מגיע אליכם") ומרנדרים שוב. זה המראה של כלל כתיבת ה-`notes` במצגת בשלב 3.

### מצב ב (חריג): כפתור בלבד
`form_action` ריק. הכפתור בדף מוביל ישר ל-`group_link` (קבוצת הוואטסאפ). אין גיליון נרשמים; הקבוצה היא הרשימה. מתאים לקהל חם, לא לקמפיין ממומן.

## 2. קבוצת וואטסאפ + לינק הזמנה

1. בטלפון: וואטסאפ → קבוצה חדשה → שם: `<project_name>` (או "<שם> · שידור חי 15.9") → יצירה (מוסיפים איש קשר אחד כדי לפתוח; אפשר להסיר אחר כך).
2. הגדרות הקבוצה → "הרשאות" → **שליחת הודעות: רק מנהלים**. קבוצה שקטה = הלינק לא נבלע, ואף אחד לא עוזב בגלל רעש.
3. "לינק הזמנה" → העתקה. זה `config.group_link`.
4. מצמידים את הודעת הפתיחה מ-`whatsapp-group.md`.
5. קבוצה מתמלאת ב-1,024 חברים. מ-800 נרשמים: פותחים "קבוצה 2" באותן הגדרות, ומחליפים את `group_link` בקונפיג + מרנדרים שוב (או מחליפים יעד בלינק המקוצר, `advanced.md`).

## 3. לפתוח ולבדוק את הדפים במחשב

הדפים הם קבצי HTML רגילים. לפתוח: לחיצה כפולה על `outputs/webinars/<slug>/landing/index.html`, או ב-Claude Code: `open landing/index.html` (Mac) / `start landing/index.html` (Windows; קו נטוי רגיל, עובד ב-Git Bash, cmd ו-PowerShell). דף התודה: `landing/thank-you/index.html`. הכל עובד מקומית: ספירה לאחור, שליחת הטופס לגיליון והמעבר לדף התודה (הבדיקה המלאה בסעיף 1.6).

נייד: מחברים את הטלפון או משתמשים ב-F12 → אייקון הנייד → 390 רוחב.
