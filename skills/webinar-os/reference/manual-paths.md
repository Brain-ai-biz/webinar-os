# מסלולים ידניים: הוראות צעד-צעד

**מתי לטעון אותי:** בשלב 5, לכל רכיב ש-`config.integrations` הגדיר כידני. נותנים למשתמש/ת רק את הסעיף הרלוונטי, לא את כל הקובץ.

## תוכן עניינים
1. לכידת לידים ב-Google Forms + Sheets
2. קבוצת וואטסאפ + לינק הזמנה
3. לינק מקוצר (Bitly)
4. זום בממשק
5. העלאת 2 דפי ה-HTML (Netlify Drop / Cloudflare Pages / וורדפרס)
6. שליחת מיילים מכל מערכת דיוור
7. צילום הקריאייטיבים

## 1. לכידת לידים ב-Google Forms + Sheets (2 מצבים)

### מצב א (מומלץ): הטופס שלנו בדף, Google Form מאחורי הקלעים

הדף נשאר מעוצב; הנתונים נוחתים בגיליון.

1. **יצירת הטופס**: forms.google.com → טופס ריק → שם: "<project_name> - נרשמים". 4 שאלות, כולן "תשובה קצרה" וחובה: שם מלא, אימייל, טלפון, ושאלה רביעית מסוג "תיבות סימון" עם אפשרות אחת: "קראתי ואני מאשר/ת את מדיניות הפרטיות ותנאי השימוש, ומעוניין/ת לקבל עדכונים" (חובה).
2. **גיליון תשובות**: לשונית "תשובות" → אייקון Sheets → יצירת גיליון. זה גיליון הלידים.
3. **כתובת השליחה**: לוחצים "שלח" → אייקון לינק → מעתיקים. מחליפים בסוף הכתובת את `/viewform` ב-`/formResponse`. זה `form_action`.
4. **שמות השדות**: פותחים את הטופס בתצוגה מקדימה (עין) → קליק ימני → "הצג מקור" (או F12) → מחפשים `entry.` ליד כל שאלה. מקבלים 3 מזהים כמו `entry.123456789`. אם זה מסובך, מבקשים מ-Claude: "תמצא/י לי את מזהי ה-entry של הטופס הזה" (Playwright / הדבקת המקור).
5. **לקונפיג**:
   ```json
   "form_action": "https://docs.google.com/forms/d/e/XXXX/formResponse",
   "form_fields": { "name": "entry.111", "email": "entry.222", "phone": "entry.333" }
   ```
   התיבה של ההסכמה נשלחת כשדה `consent=yes`; ב-Google Form היא לא נקלטת אוטומטית (אין לה entry), ולכן הרישום בגיליון הוא "כל מי שבגיליון אישר/ה" (הדף לא שולח בלי סימון). מי שרוצה עמודה מפורשת מוסיף/ה `"consent": "entry.444"` ל-`form_fields` והדף ישלח גם אותה.
6. **בדיקה**: `render_pages.py` → פותחים את `out/index.html` → נרשמים עם מייל בדיקה → השורה בגיליון תוך שניות. מוחקים אותה.

### מצב ב (הכי פשוט): הכפתור בדף מוביל ל-Google Form

אם משהו במצב א לא עובד: משאירים `form_action` ריק, ומגדירים `capture: "button-only"` עם `group_link` = הלינק לטופס של גוגל (במקום קבוצה). דף התודה לא נפתח אוטומטית; מגדירים בטופס של גוגל הודעת אישור עם לינק לקבוצה.

## 2. קבוצת וואטסאפ + לינק הזמנה

1. בטלפון: וואטסאפ → קבוצה חדשה → שם: `<project_name>` → תמונה: הקריאייטיב `tomorrow` (1:1) → יצירה (מוסיפים איש קשר אחד כדי לפתוח, אפשר להסיר אחר כך).
2. הגדרות הקבוצה → "הרשאות" → "שליחת הודעות: רק מנהלים". קבוצה שקטה = הלינק לא נבלע.
3. הגדרות → "לינק הזמנה" → העתקה. זה `group_link`.
4. הודעת פתיחה מוצמדת: "ברוכים הבאים ל-<project_name>. השידור <date_he> ב-<time>. הלינק יישלח כאן שעה לפני. עד אז, שאלה? כתבו לי בפרטי."
5. קבוצה מתמלאת ב-1,024 חברים. מעל ~700 נרשמים, פותחים "קבוצה 2" ומחליפים את היעד של הלינק המקוצר (§3). זו הסיבה לקיצור.

## 3. לינק מקוצר (Bitly חינמי)

1. bitly.com → חשבון חינמי → "Create link".
2. Destination = `group_link`. Custom back-half = `<slug>-group` (אם פנוי). Create.
3. הלינק שנוצר = `short_link`. משתמשים בו בכל מקום ציבורי.
4. חוזרים על זה ל-`broadcast_link` עם `<slug>-live`.
5. כשהקבוצה מתמלאת: Bitly → הלינק → Edit → Destination חדש. הפרסומים לא משתנים.

בלי Bitly: משתמשים בלינק המלא. עובד, פשוט אי אפשר להחליף יעד אחר כך.

## 4. זום בממשק

**פגישה (Meeting) מספיקה לרוב הוובינרים** עד 100 (חינם, 40 דקות) או 300 (Pro). "וובינר" של זום דורש תוסף בתשלום.

1. zoom.us → Schedule a Meeting.
2. Topic: `<project_name>`. When: `date_iso` `time`, Duration: `duration_min`. Time zone: Jerusalem.
3. Security: Passcode מסומן, Waiting Room **לא** מסומן (אנשים נכנסים לבד בזמן). 
4. Options: "Mute participants upon entry" מסומן. "Allow participants to join anytime" לא.
5. Save → Copy Invitation → מעתיקים רק את ה-Join URL (עם ה-pwd בתוכו). זה `broadcast_link`.
6. ביום האירוע: פותחים 15 דקות לפני, משתפים מסך עם `deck.html` במסך מלא (`F`), מקליטים לענן.

## 5. העלאת 2 דפי ה-HTML

אחרי `render_pages.py`, התיקייה `out/` מכילה `index.html`, `thank-you/index.html`, ו-`creatives/`. מעלים את **כל התיקייה** (דף התודה הוא נתיב יחסי `thank-you/`).

### Netlify Drop (דקה, בלי חשבון)
1. app.netlify.com/drop → גוררים את תיקיית `out` לדף.
2. מקבלים לינק `random-name.netlify.app`. זה `page_url`. עובד מיד, כולל `/thank-you/`.
3. כדי לשמור ולשנות אחר כך: נרשמים (חינם) ו-"Claim site". שם דומיין: Site settings → Change site name.
4. עדכון הדף: גוררים שוב את `out` על אותו אתר (Deploys → drag).

### Cloudflare Pages (חינם, דומיין משלך)
1. dash.cloudflare.com → Workers & Pages → Create → Pages → "Upload assets".
2. שם הפרויקט: `<slug>` → מעלים את תיקיית `out` → Deploy.
3. לינק `<slug>.pages.dev`. Custom domains → מוסיפים תת-דומיין שלך (אם הדומיין ב-Cloudflare, זה אוטומטי).
4. אם יש `wrangler` מותקן: `wrangler pages deploy out --project-name <slug>` (מסלול אוטומטי).

### וורדפרס
1. עמודים → הוסף חדש → כותרת `<project_name>` → בלוק "HTML מותאם אישית" → מדביקים את **כל** תוכן `index.html`. (אם התבנית מוסיפה תפריט/פוטר, מעדיפים תבנית "Blank" / "Canvas" של הערכה.)
2. חוזרים על זה לדף התודה עם slug `thank-you` תחת אותו עמוד-אב, או מעדכנים בקובץ את `THANK_YOU = "thank-you/"` לכתובת המלאה של דף התודה.
3. חלופה נקייה יותר: להעלות ב-Netlify Drop ולקשר מהאתר. הדף עצמאי ולא רב עם התבנית.

### Wix / אתר אחר
לא מדביקים את הדף בתוך Wix (הוא מגביל HTML). מעלים ב-Netlify Drop ומקשרים משם, או משתמשים ב-Wix רק לטופס ומקשרים אליו כ-`button-only`.

## 6. שליחת מיילים מכל מערכת דיוור

1. **רשימה חדשה** בשם `<project_name> - נרשמים`. אם הגיליון של Google Forms הוא המקור, מייבאים ממנו (CSV) פעם ביום עד האירוע, או מחברים Zapier/Make "שורה חדשה → נמען חדש" (אוטומטי).
2. **מייל 1 (ברוכים הבאים)**: כאוטומציה "בהצטרפות לרשימה" אם המערכת תומכת; אחרת דיוור ידני פעם ביום למצטרפים החדשים.
3. **מייל 2 ו-3**: דיוור מתוזמן לרשימה, לפי `schedule.md`. מוודאים שאזור הזמן במערכת הוא ישראל.
4. **שדות**: משתמשים ב-`[שם פרטי]` / `{{first_name}}` לפי התחביר של המערכת, רק אם השם נאסף. אחרת בלי פנייה אישית.
5. **בלי מערכת**: Gmail → הודעה חדשה → BCC (לא TO) עד 100 נמענים בכל פעם → Schedule send. מעל 100 נרשמים, שווה לפתוח מערכת דיוור חינמית.

## 7. צילום הקריאייטיבים

הקבצים ב-`out/creatives/*.html`, כל אחד 1080×1080 (עם `?story` בסוף הכתובת: 1080×1920).

- **אוטומטי** (אם Playwright/Chrome זמינים ל-Claude): "צלם/י את כל הקריאייטיבים ל-PNG, 1:1 ו-9:16".
- **ידני בכרום**: פותחים את הקובץ → F12 → Cmd/Ctrl+Shift+P → מקלידים "Capture full size screenshot" → Enter. ה-PNG יורד בגודל מלא. חוזרים עם `?story`.
- **תוסף**: GoFullPage או Awesome Screenshot, "Full page".

התוצאה: 10 קבצי PNG (5 × 2 פורמטים) לסטורי, פיד, ותמונת הקבוצה.
